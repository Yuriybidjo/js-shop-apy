Переходимо до магії сервера: переписуємо main.js
Зараз у вашому файлі products.json вже лежать правильні дефолтні товари. Тепер навчимо додаток завантажувати їх звідти асинхронно через мережу.
Крок 1: Очищення main.js від старого коду
Відкрийте файл main.js.
Знайдіть у блоці document.addEventListener('DOMContentLoaded', () => { ... }) самий початок, де перевірявся LocalStorage.

// ОЦЕЙ БЛОК ПОВНІСТЮ ВИДАЛІТЬ З FILE main.js:
if (getSafeStorageItem('myProducts').length === 0) {
  localStorage.setItem('myProducts', JSON.stringify([ ... ]));

Крок 2: Додавання асинхронної функції
Одразу під імпортами (але вище за блок DOMContentLoaded) вставте нову функцію, яка робитиме запит:

-------
// Функція для завантаження товарів із нашого локального "сервера"
async function loadInitialProducts() {
  try {
    // 1. Робимо запит до файлу. fetch повертає об'єкт відповіді сервера
    const response = await fetch('./products.json');
    
    // Перевіряємо, чи успішно пройшов HTTP-запит (код 200-299)
    if (!response.ok) {
      throw new Error(`Помилка сервера: ${response.status}`);
    }

    // 2. Декодуємо текст JSON у звичайний масив JavaScript об'єктів
    const serverProducts = await response.json();

    // 3. Зберігаємо отримані з сервера дані в LocalStorage, щоб інші функції сайту працювали як зазвичай
    localStorage.setItem('myProducts', JSON.stringify(serverProducts));
    
    console.log('Товари успішно завантажені з сервера через fetch! 🎉');
  } catch (error) {
    console.error('Не вдалося завантажити товари з сервера:', error);
  }
}

Крок 3: Асинхронний запуск рендерингу
Оскільки запит до сервера займає певний час, ми маємо спочатку дочекатися завершення функції loadInitialProducts() і лише потім малювати картки товарів.
Змініть початок вашого DOMContentLoaded так, щоб він викликав функцію через .then():
----
document.addEventListener('DOMContentLoaded', () => {
  // Запускаємо завантаження, і тільки КОЛИ воно завершиться — малюємо індикатор та вітрину
  loadInitialProducts().then(() => {
    updateCartIndicator();
    renderProducts();
  });

  // Далі йде ваш пошук, обробники кнопок модалки кошика тощо (без змін)...

Як надіслати замовлення у ваш реальний Telegram

Замість того, щоб просто виводити текст на екран, ми навчимо JavaScript робити POST-запит у Telegram. Коли клієнт натисне «Підтвердити замовлення», вам у месенджер миттєво прийде сповіщення.

Для цього нам знадобляться дві речі: Токен бота та Ваш ID чату.

Крок 1: Створення Telegram-бота
Відкрийте Telegram на телефоні чи комп'ютері
Знайдіть у пошуку офіційного бота @BotFather (біля нього має бути синя галочка).Напишіть йому команду: /newbotБот попросить назвати його (наприклад, My Study Shop Bot).
Потім він попросить унікальний юзернейм, який обов'язково має закінчуватися на _bot (наприклад, yuriy_shop_study_bot).
У відповідь @BotFather надішле вам довгий секретний рядок — це HTTP API Token (на кшталт 123456789:ABCdefGh...). Скопіюйте його.

Крок 2: Отримання вашого ID чату
Бот не може сам написати людині першим, тому спочатку знайдіть свого створеного бота в пошуку Telegram та натисніть кнопку Start (або напишіть /start).
Тепер нам треба дізнатися ваш особистий цифровий ідентифікатор, щоб бот знав, куди саме слати повідомлення:
Знайдіть у пошуку Telegram бота @userinfobot.
Напишіть йому будь-що або просто натисніть Start.
Він миттєво надішле вам рядок із цифрами (наприклад, Id: 483920192). Скопіюйте ці цифри

Крок 3: Додавання функції відправки у main.js
Відкрийте файл main.js у вашому VS Code. 
Знайдіть у самому низу (всередині DOMContentLoaded) обробник події форми замовлення orderForm.addEventListener('submit', ...).
Замініть весь цей обробник форми на новий, асинхронний варіант (не забудьте підставити у змінні ваші реальні Токен та ID):
------------------
  // 4. Оформлення замовлення та відправка в Telegram
  const orderForm = document.getElementById('order-form');
  if (orderForm) {
    // Додаємо слово async перед (event), бо всередині буде fetch запит до Telegram
    orderForm.addEventListener('submit', async (event) => {
      event.preventDefault();
      
      const customerName = document.getElementById('customer-name')?.value.trim();
      const customerPhone = document.getElementById('customer-phone')?.value.trim();
      const totalSum = document.getElementById('modal-total-sum')?.textContent || '0';

      // 1. Формуємо красивий текст повідомлення для Telegram
      let message = `🔔 <b>Нове замовлення на сайті!</b>\n\n`;
      message += `👤 <b>Покупець:</b> ${customerName}\n`;
      message += `📞 <b>Телефон:</b> ${customerPhone}\n\n`;
      message += `🛒 <b>Товари:</b>\n`;
      
      cart.forEach(item => {
        message += `• ${item.name} (x${item.quantity || 1}) — ${(parseFloat(item.price) || 0) * (parseInt(item.quantity) || 1)} ₴\n`;
      });
      
      message += `\n💰 <b>Загальна сума:</b> ${totalSum} ₴`;

      // 2. Налаштування підключення до Telegram (ПІДСТАВТЕ СВОЇ ДАНІ СЮДИ)
      const TELEGRAM_TOKEN = 'ВСТАВТЕ_СЮДИ_ВАШ_TOKEN_ВІД_BOTFATHER';
      const TELEGRAM_CHAT_ID = 'ВСТАВТЕ_СЮДИ_ВАШ_ID_ВІД_USERINFOBOT';
      const TELEGRAM_API_URL = `https://telegram.org{TELEGRAM_TOKEN}/sendMessage`;

      try {
        // 3. Робимо асинхронний POST-запит до серверів Telegram
        const response = await fetch(TELEGRAM_API_URL, {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({
            chat_id: TELEGRAM_CHAT_ID,
            text: message,
            parse_mode: 'HTML' // Дозволяє використовувати жирний шрифт <b> у тексті
          })
        });

        if (!response.ok) {
          throw new Error('Не вдалося відправити повідомлення в Telegram');
        }

        console.log('Сповіщення успішно надіслано в Telegram! 🚀');

        // 4. Якщо запит успішний, показуємо вікно успіху на сайті
        const successText = document.getElementById('success-message-text');
        if (successText) {
          successText.textContent = `${customerName}, ми зателефонуємо вам на номер ${customerPhone}. Сума до сплати: ${totalSum} ₴`;
        }

        if (checkoutBlock) checkoutBlock.style.display = 'none';
        if (successBlock) successBlock.style.display = 'block';

        // Повністю очищуємо кошик
        clearCartArray();
        localStorage.removeItem('myCart');
        updateCartIndicator();
        orderForm.reset();

      } catch (error) {
        console.error('Помилка відправки замовлення:', error);
        alert('Упс! Сталася помилка при оформленні. Спробуйте ще раз.');
      }
    });
  }
